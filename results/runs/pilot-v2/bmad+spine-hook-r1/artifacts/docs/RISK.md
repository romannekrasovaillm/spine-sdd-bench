# Риски изменения — Рекуррентные C2B-списания (подписки СБП)

- Связано: `docs/adr/ADR-008-...md` (Consequences), `docs/ACCEPTANCE.md`

## Топ-3 для комитета

R3 (гонка отзыва), R5 (регуляторное соответствие), R12 (авторизация ресурсов ТСП/RB12 — broken object authorization) — требуют решения/согласования вне команды и вынесены в `docs/DECISION.md`. R6 (пиковые окна) — эксплуатационная готовность.
