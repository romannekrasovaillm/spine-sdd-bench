# NFR изменения — Рекуррентные C2B-списания (подписки СБП)

Измеримые цели на гейтах A4/A5. Значения — baseline; финальные согласуются с бизнесом и НСПК (регламенты оператора могут быть строже). Часть значений зависит от протокола НСПК `[ТРЕБУЕТ ПРОВЕРКИ]`.

## 1. Производительность

| Метрика | Цель | Метод проверки |
|---|---|---|
| Latency регистрации согласия (API ТСП, без учёта НСПК) | p95 < 500 мс, p99 < 1 с | Нагрузочный тест, APM |
| Latency инициации списания (приём запроса ТСП, без учёта НСПК) | p95 < 400 мс, p99 < 1 с | Нагрузочный тест |
| Проверка согласия (guard `ACTIVE` + лимиты) | p95 < 50 мс | Метрика внутреннего вызова |
| Доставка нотификации согласия/списания ТСП от события НСПК | p95 < 5 с | Метрика лага очереди |
| Зачисление по списанию от подтверждения НСПК | p95 < 60 с (SLA с АБС) | Метрика процесса |
| Throughput списаний sustained | 100 TPS | Нагрузочный тест |
| Throughput пик (день биллинга, «зарплатные» дни) | 300 TPS, допустимый burst 600 TPS на 1 мин | Нагрузочный тест |
| Масштабируемость | ×2 без изменения архитектуры | Load-test 200 TPS |

## 2. Надёжность и восстановление

| Метрика | Цель | Метод проверки |
|---|---|---|
| RPO | 0 для согласий, доказательств согласий, списаний и outbox-событий | Тест отключения ноды, сверка |
| RTO (восстановление обработки) | ≤ 1 час | Chaos-тест, DR-учения |
| Двойное списание при повторе инициации | 0 (идемпотентность по `Idempotency-Key`) | Тест повторной доставки |
| Двойное зачисление по одному списанию | 0 (идемпотентность по `paymentId`) | Тест повторной доставки |
| Потеря нотификации НСПК по согласию/списанию | 0 (компенсируется сверкой и опросом статусов) | Сверка с НСПК |

## 3. Целостность согласий (новые — критичные)

| Метрика | Цель | Метод проверки |
|---|---|---|
| Списание без `ACTIVE`-согласия | 0 (в проде — 0; выборка + fitness) | Fitness-тест + прод-семплинг |
| Списание сверх лимита согласия | 0 | Тест + прод-семплинг |
| Блокировка новых списаний после отзыва | 100 %, ≤ 5 с от события НСПК; end-to-end ≤ 60 с | Тест отзыва под нагрузкой |
| Иммутабельность условий согласия | 100 % (изменение только новым согласием) | Тест попытки правки |
| Аудит переходов согласия | 100 % переходов в неизменяемом логе | Аудит, SIEM |
| Сверка согласий и списаний с НСПК | ежедневная; расхождений по завершённым — 0 | Reconciliation-отчёт |

## 4. Доступность

| Метрика | Цель | Метод проверки |
|---|---|---|
| Доступность пути «проверка согласия + инициация списания» | ≥ 99,95 % (мес.) | SLO-отчёт |
| Доступность регистрации согласия | ≥ 99,95 % (мес.) | SLO-отчёт |
| Плановая недоступность при деплоях | 0 (rolling, без downtime) | CI/CD pipeline |

## 5. Безопасность и соответствие

| Метрика | Цель | Метод проверки |
|---|---|---|
| Каналы к ОПКЦ для операций подписок | 100 % на сертифицированных СКЗИ (ГОСТ, mTLS) | ИБ-аудит |
| Доказательство согласия в покое | зашифровано 100 % | ИБ-ревью, тесты |
| Доступ к реестру согласий | привилегированный контур, RBAC, журнал доступа | RBAC-проверка, SIEM |
| ПДн плательщика | только `payerRef` (минимизация), маскирование в логах | ИБ-ревью |
| Интеграция с AML/антифрод | операции по порогам — 100 % | Тест-кейсы |

## 6. Наблюдаемость

| Метрика | Цель | Метод проверки |
|---|---|---|
| Trace id на операцию (согласие/списание) | 100 % операций | APM |
| Алерт на DLQ | DLQ > 0 → алерт за ≤ 5 мин | Мониторинг |
| Алерт «списание без ACTIVE-согласия» | немедленно (0-толерантность) | Мониторинг, SIEM |
| Лаг очереди согласий/списаний | ≤ 60 с в норме | Мониторинг |
| Отчёт незавершённых согласий/списаний | доступен всегда, актуален | Проверка |

## 7. Регуляторные цели (уточняются)

| Метрика | Цель | Метод проверки |
|---|---|---|
| Срок хранения доказательства согласия | не менее срока действия + срок, установленный регулятором `[ТРЕБУЕТ ПРОВЕРКИ]` | ИБ/юридическая служба |
| Предоставление согласия/истории списаний по запросу плательщика | ≤ 3 раб. дней `[ТРЕБУЕТ ПРОВЕРКИ]` | Регламентная проверка |

## Зависимости (внешние входы)

- Регламенты НСПК по сервису подписок: тайминги, коды, форма согласия `[ТРЕБУЕТ ПРОВЕРКИ]`.
- SLA вендора транспорта по новым операциям (согласия/списания).
- Правовое заключение по форме и сроку хранения доказательства согласия (ИБ + юридическая служба).
