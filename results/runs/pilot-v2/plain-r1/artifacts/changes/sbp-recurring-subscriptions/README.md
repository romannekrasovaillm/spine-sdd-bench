# Изменение: рекуррентные C2B-списания («СБП-подписки»)

Архитектурный пакет изменения поверх принятого решения «Платёжный шлюз СБП (C2B-приём)».
Задача бизнеса: ТСП (онлайн-кинотеатры, ЖКХ, связь) просят рекуррентные списания по согласию плательщика — сейчас каждый платёж требует QR и действия клиента.

- **Маршрут: Critical** (значимость изменения 10/15, включая security boundary / financial impact / criticality). Полное Solutioning.
- **Статус: proposed** — ждёт человеческого решения **A3** (ратификация ADR-008 и AD-009…AD-011). До A3 в реализацию не передаётся.
- **Код не писался** — только архитектурный пакет.
