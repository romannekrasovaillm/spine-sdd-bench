# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты, рекуррентные списания по согласию плательщика (подписки СБП).

- Маршрут: **Critical** (базовое решение — значимость 11/15; расширение CR-001 «подписки СБП» — 12/15).
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..008`, `ARCHITECTURE-SPINE.md`, `docs/changes/CR-001-rekurrentnye-c2b-spisaniya.md`.
- Статус: базовое решение принято (A3 от 2026-08-15: ADR-007 Accepted, AD-008 [ADOPTED]). Расширение **CR-001 «рекуррентные C2B-списания»** (ADR-008, блок AD-009) подготовлено и **ожидает человеческого решения A3** по механизму списаний и правовой модели согласия; реализация рекуррентности — только после ратификации ADR-008/AD-009 и подтверждения рекуррентного механизма в документации НСПК (протокол участника — внешний вход, помечен `[ТРЕБУЕТ ПРОВЕРКИ]`).
