# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты.

Дополнительно (изменение **CS-001**, Proposed): рекуррентные C2B-списания по согласию плательщика («подписки СБП»).

- Маршрут: **Critical** (исходно 11/15; изменение CS-001 — оценка 14/15).
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..007`, `ARCHITECTURE-SPINE.md`, пакет изменения `docs/change/c2b-subscriptions/`.
- Статус: базовое решение подготовлено; стратегия реализации (ADR-007) **принята на A3**; остаётся получить документацию НСПК (протокол участника — внешний вход, помечен `[ТРЕБУЕТ ПРОВЕРКИ]`). Изменение CS-001 (AD-009…AD-016, ADR-008) — **Proposed**, вынесено на решение A6.
