# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты, и рекуррентные C2B-списания по согласию плательщика (подписки СБП).

- Маршрут базового решения: **Critical** (значимость 11/15).
- Маршрут изменения «подписки СБП»: **High** (значимость 8/15) — см. `docs/solutioning-subscriptions.md`.
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..008`, `ARCHITECTURE-SPINE.md`.
- Статус: базовое решение подготовлено, **ожидает человеческого решения A3** по стратегии реализации (ADR-007) и получения документации НСПК. Изменение «подписки СБП» — **Proposed** (ADR-008, AD-009), ожидает утверждения человеческого решения до реализации транспорта согласий.
