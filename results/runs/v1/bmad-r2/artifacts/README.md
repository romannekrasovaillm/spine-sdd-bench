# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты, рекуррентные C2B-списания по согласию плательщика (подписки СБП).

- Маршрут: **Critical** (значимость 11/15).
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..008`, `ARCHITECTURE-SPINE.md`.
- Статус: базовое C2B-решение подготовлено (A3 по ADR-007 принято 2026-08-15); **изменение «рекуррентные C2B-списания» подготовлено как ADR-008 (Proposed) и ожидает архитектурного решения**. Протокол участника НСПК (в т.ч. рекуррентный) — внешний вход, помечен `[ТРЕБУЕТ ПРОВЕРКИ]`.
