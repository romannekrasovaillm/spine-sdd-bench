# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты.

- Маршрут: **Critical** (значимость 11/15).
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..007`, `ARCHITECTURE-SPINE.md`.
- Статус: решение подготовлено, **ожидает человеческого решения A3** по стратегии реализации (ADR-007) и получения документации НСПК (протокол участника — внешний вход, помечен `[ТРЕБУЕТ ПРОВЕРКИ]`).

## Изменение: СБП-подписки (рекуррентные C2B-списания)

Бизнес-запрос ТСП (онлайн-кинотеатры, ЖКХ, связь): рекуррентные списания по согласию плательщика. Архитектурный пакет подготовлен поверх принятого решения:

- Маршрут: **Critical** (`arch control score` = 8/15).
- Решение: `docs/adr/ADR-008-rekurrentnye-c2b-spisaniya-po-soglasiyu-platelschika-sbp-podpiski.md` (статус `Proposed`, ожидает A3).
- Новые инварианты spine: `AD-009`, `AD-010` (статус `Proposed`).
- Спецификация машин состояний: `docs/spec/recurring-consent.md`.
- Контракт API ТСП: `openapi/tsp-api.yaml` (0.2.0) и `docs/contracts/tsp-api.md` (v0.2 draft) — аддитивное расширение.
- NFR: `docs/nfr.md` §7.
