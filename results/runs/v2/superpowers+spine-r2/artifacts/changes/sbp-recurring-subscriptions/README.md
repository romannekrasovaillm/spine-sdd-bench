# Изменение: Подписки СБП (рекуррентные C2B-списания по согласию плательщика)

Архитектурный пакет изменения поверх принятого решения «Платёжный шлюз СБП (C2B-приём)».
Задача: ТСП (онлайн-кинотеатры, ЖКХ, телеком) просят рекуррентные C2B-списания по согласию плательщика;
сейчас каждый платёж требует QR и действия клиента.

- Маршрут: **Critical** (`significance_score`: score 8/15).
- Статус: **proposed** — выносится на A3 (человеческое решение), затем в передачу исполнителям.
