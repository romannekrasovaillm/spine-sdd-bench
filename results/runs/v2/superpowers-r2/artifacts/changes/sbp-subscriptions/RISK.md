# Оценка риска изменения: sbp-subscriptions

- Уровень риска: **Critical** (значимость 10/15; `arch control score`; с `criticality_or_exception` — 11/15)
- Финансовое влияние: прямое (многократные списания со счетов плательщиков)
- Контур: платёжный контур СБП / КИИ; персональные данные плательщика

## Реестр рисков

| # | Риск | Влияние | Митигация | Владелец |
|---|---|---|---|---|
| R1 | Списание без действующего согласия (ошибка проверки мандата) | Незаконное списание, регуляторный инцидент | AD-009, fitness-правило `consent-before-auto-action`, тест-шпион на адаптер, сверка | Архитектор + ИБ |
| R2 | Двойное списание при повторе или новом ключе ТСП | Двойное списание у плательщика | ADR-010: ключ + ключ периода + запрет повторной отправки при неопределённости; fitness `idempotency-key` | Архитектор |
| R3 | Повторная отправка при неопределённом исходе | Двойное списание / потеря списания | AD-010, `OPKC_UNKNOWN`, опрос статуса и сверка; fitness `unknown-outcome-no-resend` | Архитектор |
| R4 | Внешний вход недоступен: протокол сервиса мандатов СБП не подтверждён | Блокер сроков; неопределённость полей/лимитов | Ранний запрос документации НСПК; проектирование ядра на моке адаптера; `[ТРЕБУЕТ ПРОВЕРКИ]` | Проектный офис / НСПК |
| R5 | ПДн и доказательство согласия расширяют поверхность защиты | Нарушение 152-ФЗ, утечка | ADR-009: минимизация, append-only аудит, RBAC/4-eyes, шифрование, `no-pii-in-logs` | ИБ |
| R6 | Гонка «отзыв согласия ↔ списание» | Списание после отзыва | Гонка разрешается в пользу запрета (AD-010/ADR-009); chaos-тест | Архитектор |
| R7 | Вендор транспорта не поддерживает сервис подписок | Подписочный сценарий не реализуем через выбранного вендора | RFP G8, POC P9–P11, kill criteria; базовый C2B не затрагивается | Закупки + архитектор |
| R8 | Ответственность за календарь у ТСП (пропуски/дубли на стороне ТСП) | Недополучение, споры | Наблюдаемость списаний, лимиты мандата, понятная модель ошибок | Продукт |

## Критерий пересмотра риска

Появление хотя бы одного инцидента R1–R3 в пилоте — стоп новой волны, разбор, при подтверждении системного дефекта — откат (см. `ROLLBACK.md`).
