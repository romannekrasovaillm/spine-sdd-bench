# ADR изменения — Подписки СБП

- Решение: `docs/adr/ADR-008-podpiski-sbp-rekurrentnye-c2b-spisaniya-po-soglasiyu-platelschika.md`
- Статус: **Proposed** (ожидает A3 — человеческое архитектурное решение).
- Выбор: расширение существующего СБП-шлюза подписочным контуром (согласие + подписка + планировщик) внутри доверенной зоны; рекуррентное списание — обычный платёж со ссылкой на подписку (ветвь без QR, `T4a`), зачисление только из `PAID`; идемпотентность по `(subscriptionId, billingPeriod, attempt)`; протокол подписок — в единственном адаптере ОПКЦ; API ТСП расширяется аддитивно (v0.2, 0.1-совместимо).
- Отвергнутые альтернативы: отдельный сервис подписок вне шлюза; полностью вендорская «коробка»; встраивание в платёжный движок без выделенного контура.
- Обратимость: `costly`.
- Альтернативы, отрицательные последствия и expiry-условие — в ADR-008. Затронутые инварианты: AD-001..AD-013 (новые — AD-009..AD-013).
