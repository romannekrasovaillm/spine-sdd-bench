# Инварианты спайна, затрагиваемые изменением — Подписки СБП

Полный спайн: `ARCHITECTURE-SPINE.md` (AD-001..AD-013). Изменение добавляет AD-009..AD-013; AD-001..AD-008 не переписываются.

- **AD-009** (новый). Списание только по действующему согласию и в его пределах (статус `ACTIVE`, `amount ≤ maxAmount`, `period` совпадает, `scheduledAt < validUntil`); подписка — только на мандат того же ТСП; один мандат — одна активная подписка на ТСП.
- **AD-010** (новый). Не более одного **зачисленного** списания на `(subscriptionId, billingPeriod)`; ключ инициации `(subscriptionId, billingPeriod, attempt)`; транзиентный ретрай — тот же `paymentId`.
- **AD-011** (новый). Приоритет отзыва: подтверждённый переход в `REVOKING`/`REVOKED` исключает мандат из планировщика; «в полёте» — runbook (≤1 на согласие, компенсация возвратом).
- **AD-012** (новый). Единая статусная машина и шлюз зачисления; ветвь без QR (`CREATED → PAID`, `T4a`); зачисление только из `PAID`.
- **AD-013** (новый). Разделение «согласие ≠ подписка ≠ платёж».

Затронутые существующие инварианты: AD-001 (периметр расширяется, изоляция сохраняется), AD-002 (атомарные переходы — для новых автоматов), AD-003 (новый ключ идемпотентности), AD-004 (контракт адаптера расширяется), AD-005 (правило не меняется; подписки ему подчиняются), AD-006/AD-007 (ПДн согласия, аудит), AD-008 (scope вендора расширяется).
