# Оценка риска — Подписки СБП

- **Уровень:** **Critical** — Architecture Significance Score 11/15 (`arch-be control score`), финансовое влияние + критичность + платёжный контур.
- **Реестр рисков:** полный — `docs/spec/subscriptions.md` (Риски), `docs/solutioning-subscriptions.md` §6.2/§7, `changes/sbp-subscriptions/REVIEW.md` (находки ревью).

Ключевые риски:

| Риск | Влияние | Митигация |
|---|---|---|
| Двойное списание (повтор планировщика/таймаут) | финансовый инцидент, споры | детерминированный ключ `(subscriptionId, billingPeriod, attempt)`, AD-010, тест |
| Списание без/вопреки согласию (лимит, срок, отзыв) | регуляторный (161-ФЗ), репутация | guard'ы §2.1 в транзакции, приоритет отзыва AD-011, runbook |
| Межтенантная привязка мандата | утечка/несанкционированное списание | проверка владения мандатом, `MANDATE_NOT_OWNED`, аутентификация `tspId` |
| Недокументированный протокол НСПК (подписки) | переделка контракта адаптера | `[ТРЕБУЕТ ПРОВЕРКИ]`, ADR-008 expiry-условие, расширение RFP (G8/P9) |
| Пики планировщика на календарные даты | деградация, массовые отказы | разнесение расписаний, queue load leveling, ёмкость ≥720k/час, NFR §7 |
| Уведомление плательщику вне канала эквайера | несоответствие регламенту | R5: инициация через ОПКЦ, доставка — банк плательщика/НСПК; открытый вопрос |
| ПДн плательщика (хранение/удаление) | 152-ФЗ | минимизация, шифрование, ретенция при `REVOKED`, ИБ (§5) |
