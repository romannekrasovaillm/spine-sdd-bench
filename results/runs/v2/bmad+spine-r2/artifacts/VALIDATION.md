## 2. Автоматические тесты (на walking skeleton, моки)

- **Недостижимость списания без согласия** (AC-6): property/state-тест — из `PENDING_CONSENT`/`SUSPENDED`/`REVOKED`/`EXPIRED` списание невозможно; счётчик вызовов адаптера = 0.
- **Идемпотентность периода** (AC-7/AC-12): повтор и конкурентный доступ к `(subscriptionId, billingPeriod)` → одна попытка, одна проводка.
- **Зачисление только из `PAID`** (AC-4): недостижимость вызова АБС из `SCHEDULED`/`CREATED`.
- **Дубль нотификаций** (AC-8): повтор `eventId` не меняет состояние.
- **Отзыв** (AC-9): после `subscription.revoked` число списаний с временем > времени отзыва = 0.
- **Лимиты/срок/число** (AC-10): граничные кейсы суммы/периода/`maxDebits`.
- **Отказ АБС** (AC-11): chaos-тест — плановое списание не теряется, сверка компенсирует.
- **Контракт** (AC-13/AC-14): `openapi_lint`, `contract_diff`.
- **Нагрузка** (AC-15…18): управление темпом массовых списаний; разовый приём не ниже SLO.
