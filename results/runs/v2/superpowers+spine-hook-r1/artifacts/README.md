# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты. Отдельным эпиком поверх принятого решения — **СБП-подписки** (рекуррентные C2B-списания по согласию плательщика, ADR-008).

- Маршрут: **Critical** (базовый C2B — значимость 11/15; эпик подписок — 8/15).
- Инварианты: `ARCHITECTURE-SPINE.md` — AD-001..AD-008 (базовый C2B) и AD-009..AD-012 (подписки).
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..008`, `docs/spec/mandate-state-machine.md`, `openapi/tsp-api.yaml` (v0.2.0).
- Статус: базовое решение подготовлено, **A3 по стратегии реализации (ADR-007) принято 2026-08-15**. Эпик СБП-подписок (ADR-008) — **ожидает человеческого решения A3**. Документация НСПК — внешний вход (протокольные детали помечены `[ТРЕБУЕТ ПРОВЕРКИ]`).
