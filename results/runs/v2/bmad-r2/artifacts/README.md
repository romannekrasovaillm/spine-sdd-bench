# Платёжный шлюз СБП (C2B-приём)

Проектирование платёжного шлюза банка к Системе быстрых платежей (СБП): приём C2B-платежей от ТСП через ОПКЦ СБП (АО «НСПК»), зачисление на счета ТСП в АБС, возвраты, а также **подписки СБП** — рекуррентные списания по согласию плательщика (ADR-008).

- Маршрут: **Critical** (значимость 11/15). Изменение «подписки СБП» — маршрут **Critical (12/15)**, тип — расширение принятого решения.
- Ключевые документы: `docs/solutioning.md`, `docs/nfr.md`, `docs/adr/ADR-001..008`, `ARCHITECTURE-SPINE.md` (AD-001..AD-010), `openapi/tsp-api.yaml` (v0.2.0).
- Статус: базовое решение подготовлено, **ожидает человеческого решения A3** по стратегии реализации (ADR-007) и получения документации НСПК (протокол участника — внешний вход, помечен `[ТРЕБУЕТ ПРОВЕРКИ]`). Изменение «подписки СБП» — **ожидает человеческого решения A3′** (ратификация ADR-008 и scope); пакет изменения — `docs/changes/sbp-subscriptions/`.
